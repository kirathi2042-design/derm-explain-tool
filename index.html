如何新增皮膚病模板

  1. 用 ChatGPT 產生新的 conditionTemplates JavaScript 物件。
  2. 醫師確認醫療內容與翻譯後，貼到 conditions.js。
  3. 推送到 GitHub 後，GitHub Pages 會更新網站。

安全提醒

本工具僅供皮膚科臨床溝通輔助，不能取代醫師判斷。請依實際病情調整說明內容。請勿輸入病人姓名、身分證字號、病歷號、生日或其他可識別個資。
